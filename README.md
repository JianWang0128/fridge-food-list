# fridge-food-list

冰箱食物清单 - Flutter Web应用

## 项目简介

一个简单易用的冰箱食物管理应用，支持：
- 📱 网格布局显示食物清单
- ➕ 轻松添加新食物
- 🗑️ 一键删除食物项目
- 🎨 智能emoji图标匹配（支持137种食物）
- 💾 本地数据存储
- 🌐 网页版部署

## 技术栈

- **Flutter**: 跨平台UI框架
- **Dart**: 编程语言
- **GitHub Pages**: 免费静态网站托管
- **PWA**: 渐进式Web应用

## 部署说明

### 本地开发
```bash
flutter pub get
flutter run -d chrome
```

### 网页部署
```bash
flutter build web
# 然后按照部署指南操作
```

### 脚本工具
- `deploy_github.sh`: 部署到GitHub Pages
- `push_to_github.sh`: 推送代码到GitHub
- `start_web_server.sh`: 本地测试服务器

## 功能特性

- ✅ 响应式设计，适配各种屏幕
- ✅ 离线工作，无需网络连接
- ✅ PWA支持，可添加到桌面
- ✅ 智能食物图标识别
- ✅ 本地数据持久化
